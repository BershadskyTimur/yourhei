## 1. Продукт

YourHEI помогает подобрать учебное заведение (вуз, колледж, школу и др.) в странах Кавказа, Центральной Азии, Восточной Европы, Европы и Азии.

Путь пользователя: карта на главной → регистрация → подробный опрос → подборка заведений → карточка заведения.

Монетизация позже: бесплатная версия с рекламой и ограничениями и платная (полный поиск, ИИ-пояснения). **Сейчас всё бесплатно, без рекламы и оплаты.** Но закладывай архитектуру: у пользователя есть поле тарифа (`plan: free | premium`), в вёрстке не должно быть решений, мешающих потом добавить рекламные блоки.

Аудитория: абитуриенты и студенты (от 14/16 лет, см. раздел 6) и их родители.

## 2. Стек

- Next.js (App Router) + TypeScript (strict) + Tailwind CSS.
- Supabase: Postgres + PostGIS, Auth (почта и пароль + вход через Google), Row Level Security на всех таблицах, Storage.
- Карта: MapLibre GL JS с кластеризацией. Тайлы — бесплатный провайдер на данных OpenStreetMap (выбери, согласуй с владельцем). Атрибуция OSM обязательна.
- Переводы: next-intl, язык в URL (`/ru`, `/en`, `/ka`, `/es`, `/zh`).
- Темы: CSS-переменные + переключатель (next-themes или аналог).
- Формы: react-hook-form + zod.
- Тесты: Vitest для логики (подбор, нормализация оценок, возраст); Playwright для ключевых сценариев.
- Хостинг: Vercel. Бесплатный тариф Vercel предназначен для некоммерческих проектов: пока сайт без рекламы — ок, перед запуском рекламы нужно пересмотреть тариф или хостинг. Напомни владельцу об этом на этапе 6.
- Капча: Cloudflare Turnstile (невидимая).
- Письма и задачи по расписанию: сервис с бесплатным тарифом (например, Resend) и ежедневная задача по расписанию — выбор согласуй с владельцем.
- Курсы валют: бесплатный источник, который покрывает валюты СНГ и Азии (GEL, KZT, UZS, AMD, AZN, RUB, KGS, CNY, KRW, INR и т. д.), кэш раз в сутки. Выбор согласуй с владельцем.

## 3. Дизайн

**Палитра (обновлено: коричневый заменён на оранжевый и золотой):** оранжевый, золотой, белый, чёрный.
- Светлая тема: фон белый, текст почти чёрный, оранжевый и золотой — акценты.
- Тёмная тема: фон тёплый чёрный `#0f0e0c`, акценты светлее (оранжевый `#f97316`, золотой `#fbbf24`).
- Контраст текста не ниже WCAG AA (4.5:1, для крупного текста 3:1); это проверяет тест `src/config/palette.test.ts`.
- Фактические значения — в токенах `src/app/globals.css` (оранжевый `#c2410c` / текст `#a84508` в светлой теме, золотой `#e0a100`).
- Все цвета — токены (CSS-переменные), никаких цветов прямо в компонентах.

**Настроение:** тёплый, уютный, немного «академичный»; скругления, много воздуха, аккуратная типографика.

**Шрифты:** обязана поддерживаться кириллица, латиница, грузинский (мхедрули) и китайский (упрощённый). Например, семейство Noto Sans (Noto Sans, Noto Sans Georgian, Noto Sans SC) через next/font, китайский шрифт подгружать только для `/zh`.

**Вёрстка:** сначала мобильная версия. Грузинские слова длинные, китайский текст плотный — кнопки, меню и карточки должны это выдерживать (перенос, без обрезания).

**Доступность:** работа с клавиатуры, видимый фокус, подписи для экранных читалок, точки на карте отличаются не только цветом (см. раздел 7).

## 4. Языки

- Старт: русский, английский, грузинский, испанский, китайский (упрощённый). Архитектура должна позволять добавить язык одним файлом переводов + записью в конфиге. Ничего, что мешало бы позже добавить языки с письмом справа налево.
- Первый визит: язык по настройкам браузера, дальше — выбор пользователя.
- Данные заведений: названия хранятся в оригинале + переводы (`jsonb`). Текстовые поля карточек — переводы в `jsonb` `{ru, en, ka, es, zh}`. Если перевода на язык сайта нет — показывать английский (или русский) с пометкой «перевод недоступен».
- Структурные данные (цифры, даты, коды) не переводятся — подписи к ним берутся из файлов переводов.

## 5. Регионы и страны

- Список стран — ISO 3166-1, подрегионы — UN M49.
- Стартовые макрорегионы (справочник в БД, редактируется в админке, страна может входить в несколько регионов):
  1. **«Кавказ, Центральная Азия и Восточная Европа»** (рабочее название вместо «СНГ», т. к. Грузия, Украина и др. не входят в СНГ): Армения, Азербайджан, Беларусь, Грузия, Казахстан, Кыргызстан, Молдова, Россия, Таджикистан, Туркменистан, Узбекистан, Украина.
  2. **Европа** — все страны Европы по UN M49.
  3. **Азия** — все страны Азии по UN M49.
- В выборе стран страны сгруппированы по подрегионам (например, «Восточная Азия», «Западная Европа») с кнопками «выбрать все / снять все» для группы.
- Вопросы спорных территорий (подписи, отдельные «страны») не решай сам — вынеси владельцу.

## 6. Возрастной порог

- Таблица `country_age_thresholds` (страна → минимальный возраст регистрации), редактируется в админке.
- Значения по умолчанию: страны ЕС/ЕЭЗ, Великобритания, Швейцария, **Грузия** — 16; **Индия** — 18; остальные — 14. Все значения помечены «требует юридической проверки».
- Порог определяется по **стране проживания** пользователя.
- При регистрации: галочка «Мне исполнилось {N} лет» (N подставляется по стране проживания) + автоматическая проверка даты рождения по той же таблице.
- Если возраст ниже порога — вежливое сообщение, аккаунт не создаётся, введённые данные не сохраняются.

## 7. Типы заведений

Справочник `institution_types` (редактируется в админке): код, цвет точки, иконка, переводы названий.

| Код | Название | Цвет точки |
|---|---|---|

## 8. Главная страница

- Первый экран — карта на всю ширину, доступна без регистрации.
- Сверху фильтры по типам (с легендой) и поиск по названию / городу.
- Отдалённые точки группируются в кластеры с числом.
- Клик по точке — мини-карточка: название, тип, город, страна, кнопка «Подробнее» (ведёт на карточку заведения).
- Ниже: описание сайта, «Как это работает» (3 шага: регистрация → опрос → подборка), кнопка «Начать подбор».
- Шапка: логотип/название YourHEI, переключатель языка, переключатель темы, вход/профиль. Подвал: о проекте, контакты/поддержка, политика конфиденциальности, условия использования.

## 9. Регистрация

Пошаговый мастер с полосой прогресса. До создания аккаунта введённое сохраняется в браузере, чтобы не потерять при перезагрузке; после создания — в БД.

**Шаг 1. Что ищете**
- Макрорегионы (можно несколько) → страны (по умолчанию выбраны все страны региона, пользователь снимает ненужные).
- Типы заведений (можно несколько).

**Шаг 2. О себе**
- Дата рождения.
- Пол: мужской / женский / не указывать (подсказка, зачем: школы раздельного обучения, общежития).
- Страна проживания.
- Гражданство — можно указать несколько.
- Галочка возраста (раздел 6).

**Шаг 3. Документы** — по каждому статус «есть / оформляю / нет»:
- загранпаспорт;
- учебная виза или ВНЖ (если есть — в каких странах);
- аттестат / диплом (или ожидаемая дата получения);
- выписка оценок (транскрипт);
- апостиль или консульская легализация документов;
- нотариальный перевод документов;
- признание (нострификация) документов об образовании;
- подтверждение финансов (выписка, спонсорское письмо, блокированный счёт);
- медицинская страховка;
- для несовершеннолетних — нотариальное согласие родителей на учёбу за рубежом.

**Шаг 4. Аккаунт**
- Почта + пароль (требования к надёжности) или вход через Google.
- Обязательное согласие с политикой конфиденциальности и условиями; отдельная необязательная галочка на рассылку.
- Невидимая капча. Подтверждение почты.

После регистрации сразу предлагается опрос (можно отложить).

**В профиле:** редактирование всех данных, «Скачать мои данные», «Удалить аккаунт и все данные».

## 10. Опрос

### Механика
- Адаптивный: показывать только блоки, относящиеся к выбранным типам заведений и уровню.
- Сохранение после каждого ответа, полоса прогресса, необязательные вопросы можно пропустить, ответы можно изменить позже.
- **Вопросы задаются конфигом, а не отдельными компонентами**: у каждого вопроса `id`, тип (один выбор, несколько, число, шкала, поиск по списку, дата…), варианты, обязательность, условие показа (`showIf`), назначение (`filter | score | info`), переводы. Новый вопрос добавляется правкой конфига.
- Ответы хранятся с версией конфига опроса.

### Справочники (отдельные файлы данных с переводами)
- Специальности: классификатор ISCED-F 2013 (широкие, узкие и детальные направления).
- Школьные профили.
- Предметы.
- Системы оценок: минимум, максимум, проходной балл, направление шкалы (в немецкой 1 — лучшая), правило перевода в 0–100. Минимум: 5-, 10-, 12-, 20-, 100-балльные, GPA 4.0, проценты, IB, немецкая 1–6. В интерфейсе подписывать «приблизительно».
- Экзамены со шкалами баллов: ЕГЭ, ОГЭ, ЕНТ, ЦЭ/ЦТ (Беларусь), НМТ (Украина), национальные экзамены Грузии, ОРТ (Кыргызстан), Gaokao, CSAT (Корея), JEE/NEET (Индия), Abitur, Baccalauréat, Matura, A-levels, IB, AP, SAT, ACT, GRE, GMAT. Список расширяемый.
- Языки (ISO 639-1).
- Языковые сертификаты со шкалами и соответствием уровням CEFR: IELTS, TOEFL iBT, Duolingo English Test, Cambridge, TestDaF, Goethe, DSH, DELF/DALF, DELE, SIELE, HSK, JLPT, TOPIK, ТРКИ, CILS/CELI.

### Вопросы

**А. Цель**
1. Уровень: школа, колледж, подготовительный год (foundation), бакалавриат, магистратура, PhD, языковые курсы.
2. Ситуация: поступаю впервые / хочу перевестись с зачётом предметов / второе высшее.
3. Когда начать: семестр и год.
4. Формат: очно / онлайн / смешанный.

**Б. Направление**
5. Направления — до 3 с приоритетом (ISCED-F, с поиском и поддеревом до конкретной специальности).
6. Уверенность: точно знаю / есть пара вариантов / не знаю, помогите. При «не знаю» — **мини-тест интересов по модели RIASEC** (10–15 вопросов, вопросы написать самостоятельно, не копировать чужие тесты). Результат — 2–3 предложенных направления ISCED-F, которые пользователь может принять.

**В. Учёба и результаты**
8. Текущий уровень образования и год окончания.
9. Средний балл с выбором системы оценок.
10. Лучшие предметы и оценки по ним.
11. Экзамены и баллы (из справочника).
12. **Языки:** выбор любых языков из полного списка; для каждого самооценка по понятной шкале с подсказками:
    - «знаю несколько фраз» (A1);
    - «простые бытовые темы» (A2);
    - «общаюсь в поездках и на работе» (B1);
    - «свободно обсуждаю большинство тем» (B2);
    - «могу учиться на этом языке» (C1);

    - «родной».

13. На каких языках готовы учиться; готовы ли к подготовительному языковому году.
14. Олимпиады и конкурсы: предмет, уровень (школьный / региональный / национальный / международный), место.
15. Достижения: проекты, публикации, спорт, творческое портфолио, волонтёрство.
16. Для магистратуры и PhD: специальность диплома, стаж работы, тема исследований.
17. Готовы ли к вступительным экзаменам в вузе, собеседованию, творческому конкурсу.

**Г. Деньги**
18. Бесплатно / платно / рассмотрю оба.
19. Бюджет в год отдельно на обучение и на проживание, в выбранной валюте.
20. Нужна ли стипендия; рассматриваете ли образовательный кредит.

**Д. Заведение**
21. Важность рейтинга: топ мира / топ страны / неважно.
22. Государственное / частное / неважно; большое / небольшое / неважно.
23. Стратегия: только надёжные шансы / сбалансированно / амбициозно.
24. Важны ли стажировки и практика, двойной диплом, семестр по обмену.
25. Важно ли, чтобы диплом признавался в стране проживания / гражданства.

**Е. Жизнь**
26. Город: мегаполис / средний / маленький студенческий / неважно.
27. Климат: тёплый / умеренный / холодный / неважно.
28. Нужно ли общежитие.
29. Хотите ли работать во время учёбы.
30. Планы после учёбы: остаться в стране / вернуться домой / пока не знаю.
31. Едете ли с партнёром или детьми (необязательно).
32. Нужна ли доступная среда (необязательно, есть «не указывать»).

**Ж. Только для школ:** в какой класс поступать; программа (национальная / IB / A-levels / американская); пансион или проживание с семьёй; совместное или раздельное обучение.

**З. Только для колледжей:** профессия; хотите ли потом перевестись в вуз.

**И. Финал:** выберите 3 самых важных пункта: цена, престиж, страна и город, шансы поступить, направление, перспективы работы. От выбора зависят веса при подсчёте баллов.

## 11. Подбор

Вся логика — чистые функции в отдельном модуле с юнит-тестами. Результаты сохраняются и пересчитываются при изменении профиля или опроса. В подборе участвуют только **опубликованные (проверенные) данные**.

### Жёсткие фильтры
- страна ∈ выбранных; тип ∈ выбранных; программа нужного уровня;
- язык обучения ∈ языков пользователя (самооценка ≥ B2 или сертификат) — либо готовность к подготовительному языковому году;
- формат;
- бесплатно / платно;
- стоимость обучения ≤ бюджет × 1.15 (с пересчётом валют);
- есть набор в нужный период;
- для школ — подходящий класс.

### Баллы 0–100 (компоненты)
- академическое соответствие: нормализованный балл и экзамены против требований программы;
- совпадение направления: та же детальная специальность ISCED-F = 100, то же узкое направление = 70, то же широкое = 40;
- престиж: рейтинг против предпочтения;
- город, климат, размер, тип собственности;
- практика / двойной диплом / обмен;
- работа во время и после учёбы, признание диплома, общежитие;
- запас по бюджету.

Веса: базовые + усиление для 3 приоритетов из финального вопроса. Если у заведения нет данных по компоненту — компонент исключается, веса перенормируются, в интерфейсе пометка «нет данных».

### Результат
- Три группы: **надёжные** (все требования выполнены с запасом), **подходящие** (выполнены), **амбициозные** (чуть ниже требований или высокий конкурс). Ответ о стратегии влияет на то, сколько показывать в каждой группе.
- У каждого заведения: балл, **«почему подходит»** (3 главных компонента) и **«чего не хватает»** (например: «нужен IELTS 6.5, у вас 6.0»). Тексты собираются по шаблонам, без ИИ.
- Заложи интерфейс «поставщика пояснений», чтобы позже в платной версии подключить ИИ (Claude API) без переделки.

## 12. Карточка заведения

URL: `/{язык}/institutions/{страна}/{slug}`. Открыта без регистрации.

- **Шапка:** название в оригинале и на языке сайта, тип (цвет и иконка как на карте), страна и город, государственное / частное, год основания, официальный сайт, мини-карта. Логотип и фото — только из открытых лицензий (например, Wikimedia Commons с атрибуцией) или от самого заведения.
- **Рейтинги:** название рейтинга, год, позиция, ссылка на источник. Таблицы рейтингов целиком не копировать.
- **Программы:** уровень, направление, язык, длительность, формат, стоимость в год, даты начала.
- **Поступление:** документы, минимальные баллы, языковые сертификаты, вступительные испытания, собеседование, дедлайны, сбор за подачу, ссылка на подачу.
- **Деньги:** обучение, общежитие, примерная стоимость жизни в городе, стипендии и гранты. Цены в валюте пользователя «≈» + оригинальная валюта.
- **Для иностранцев:** виза, признание диплома, подготовительный год, работа во время и после учёбы (из данных страны).
- **«Ваши шансы»** (только для вошедших, прошедших опрос): группа, балл, почему подходит, чего не хватает, чек-лист документов.
- **Внизу:** источники, дата проверки, статус «проверено», кнопки «в избранное», «сравнить», «сообщить об ошибке».

Заведения без опубликованной карточки: на карте и на странице показываются базовые данные из открытых баз + ссылка на официальный сайт + пометка «подробные данные скоро появятся».

## 13. Данные по странам

Заполняются один раз на страну (не дублируются в карточках), каждое поле с источником и датой проверки:
- учебная виза (кратко + ссылка на официальный источник);
- право работать во время учёбы; рабочая виза для выпускников;
- примерная стоимость жизни (по крупным городам);
- валюта; начало учебного года;
- признание иностранных дипломов / соглашения о признании;
- централизованные системы подачи документов, если есть;
- возрастной порог (раздел 6).

## 14. Функции пользователя

- **Избранное.**
- **Сравнение** 2–3 заведений рядом по одинаковым строкам.
- **Чек-лист поступления:** для каждого заведения из избранного — требования против документов из профиля, чего не хватает, дедлайны.
- **Напоминания на почту** о дедлайнах (за 30, 7 и 1 день), можно отключить.
- **Валюта отображения:** по умолчанию по стране проживания, можно сменить.
- **«Сообщить об ошибке»** на карточке → очередь в админке.
- **Поддержка / контакты:** форма обращения, в том числе для заведений, которые хотят обновить свою страницу.

## 15. Админ-панель (`/admin`, роль admin)

- Роли в схеме: `admin`, `moderator`, `institution_rep`. Интерфейс сейчас только для admin.
- **Дашборд:** сколько карточек опубликовано по странам, пользователи, открытые жалобы, устаревшие карточки.
- **Импорт открытых данных** (названия, координаты, сайты): ROR (CC0), Wikidata (CC0), OpenStreetMap (ODbL, нужна атрибуция). Школы из OSM — только по выбранной стране, по запросу (объём огромный). Дедупликация по ROR/Wikidata ID, сайту, названию и координатам.
- **Импорт черновиков** из `data/drafts/` (формат — в `DATA_COLLECTION.md`): проверка по схеме, затем в очередь.
- **Очередь проверки:** старое и новое значение рядом с подсветкой изменений, ссылки на источники, уровень уверенности. Каждое поле: одобрить / исправить / отклонить; кнопка «одобрить всё». При одобрении — публикация и `verified_at`.
- **Редакторы:** заведения, программы, страны, справочники (типы, регионы, возрастные пороги, экзамены, системы оценок, специальности).
- **Жалобы** пользователей.
- **Устаревание:** карточки с `verified_at` старше 12 месяцев — в список «на перепроверку».
- **Журнал изменений:** кто, что, когда изменил.

## 16. Данные, безопасность, приватность

### Модель данных (ориентир, можно уточнить)
`countries`, `regions`, `region_countries`, `country_age_thresholds`, `institution_types`, `institutions` (точка PostGIS, тип, страна, город, названия jsonb, сайт, собственность, год основания, внешние ID: ror/wikidata/osm, статус `draft | published`, `verified_at`), `programs` (уровень, код ISCED-F, языки, длительность, формат, стоимость: сумма + валюта + период + для кого, наборы, требования jsonb, дедлайны, сбор, ссылка на подачу), `scholarships`, `rankings`, `sources` (сущность, поле, url, дата, уверенность), `drafts`, `field_reviews`, `complaints`, `profiles` (дата рождения, пол, страна проживания, гражданства, `plan`, роль), `user_documents`, `user_languages`, `survey_answers` (jsonb + версия конфига), `match_results`, `favorites`, `reminders`, `exchange_rates`, `audit_log`.

### Безопасность и приватность
- RLS на всех таблицах: пользователь видит только своё, публичные данные — только опубликованные, admin — всё.
- Ограничение частоты запросов для входа, регистрации, жалоб, форм.
- Собирать только нужные данные; в интерфейсе объяснять, зачем каждое личное поле.
- Страницы «Политика конфиденциальности» и «Условия использования» — шаблоны с пометкой «требует проверки юристом».
- Экспорт и удаление данных пользователем.
- Сейчас никаких сторонних трекеров. Заложи место под баннер согласия на cookies (понадобится с аналитикой и рекламой).
- На будущее: пользователям младше 18 — только неперсонализированная реклама.

## 17. Этапы

**Этап 1. Основа**
- Проект, Tailwind, токены палитры, две темы с переключателем, 5 языков с переключателем, шапка и подвал, `CLAUDE.md`, `PROGRESS.md`.
- Подключение Supabase (пошаговая инструкция для владельца).
- Главная: карта с типами, легендой, фильтрами, кластерами, мини-карточкой; тестовые данные 30–50 заведений Грузии и ещё одной страны; описание и «Как это работает».
- Первый деплой на Vercel (инструкция для владельца).

**Этап 2. Аккаунты**
- Регистрация по шагам (раздел 9), возрастные пороги, вход через Google, подтверждение почты, капча, профиль, экспорт и удаление данных, страницы политики и условий.

**Этап 3. Опрос**
- Движок опроса на конфиге, все вопросы раздела 10, справочники, мини-тест RIASEC, нормализация оценок + тесты.

**Этап 4. Данные и админка**
- Полная схема БД, данные стран, страница карточки, админ-панель (раздел 15), импорт открытых данных, импорт черновиков и очередь проверки, жалобы, журнал.
- Сверь схему импорта с форматом в `DATA_COLLECTION.md`; если формат меняется — обнови этот файл.

**Этап 5. Подбор**
- Движок подбора (раздел 11) + тесты, страница результатов с тремя группами и пояснениями, избранное, сравнение, чек-лист, напоминания.

**Этап 6. Запуск**
- SEO: метаданные, `sitemap.xml`, `hreflang`, разметка schema.org (EducationalOrganization / CollegeOrUniversity).
- Курсы валют, устаревание данных.
- Производительность карты на десятках тысяч точек (при необходимости — загрузка по видимой области или векторные тайлы).
- Проверка доступности, финальный деплой, напоминание про тариф хостинга.
