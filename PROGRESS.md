# PROGRESS — YourHEI

Обновлено: 2026-10-05.

## Этап 1 «Основа»

**Статус: код готов и проверен у меня; осталось два шага руками владельца — Supabase и Vercel** (инструкция: [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md)).

### Сделано
- Проект Next.js 16 + TypeScript (strict) + Tailwind v4, git, `CLAUDE.md`, `PROGRESS.md`, `.env.example`.
- Дизайн-токены (коричневый, белый, оранжевый, золотой) в `src/app/globals.css`, светлая и тёмная темы с переключателем. Контраст всех пар «текст/фон» по WCAG AA проверяет тест `src/config/palette.test.ts` (оранжевая кнопка в светлой теме — тёмный оттенок `#B85A0F` с белым текстом, в тёмной — `#E07B24` с чёрным).
- 5 языков через next-intl (`/ru /en /ka /es /zh`): выбор по языку браузера при первом визите, переключатель, все тексты в `messages/*.json`, тест на совпадение ключей. Шрифты Noto Sans (латиница, кириллица), Noto Sans Georgian, Noto Sans SC (только для `/zh`).
- Шапка, подвал, страницы «О проекте», «Контакты», «Политика», «Условия» (последние две — шаблоны с пометкой «требует проверки юристом»), страница «Скоро» для входа и регистрации, страница «не найдено», место под баннер cookies (`ConsentBannerSlot`).
- Главная: карта MapLibre + OpenFreeMap (данные OSM, атрибуция на карте и в подвале), кластеры, точки с цветом **и** иконкой, фильтры-легенда по типам, поиск по названию/городу (с учётом переводов), мини-карточка, «Подробнее», блоки «Что такое YourHEI» и «Как это работает». Карта меняет стиль вместе с темой.
- Временная страница заведения `/{язык}/institutions/{страна}/{slug}` (базовые данные + «подробные данные скоро появятся»), чтобы кнопка «Подробнее» не вела в пустоту. Полная карточка — этап 4.
- Supabase: `supabase/migrations/0001_stage1.sql` (PostGIS, `institution_types`, `institutions`, представление `map_institutions`, права только на чтение) и `supabase/seed.sql`. Без ключей сайт берёт те же данные из `data/seed/institutions.json`.
- 45 тестовых заведений (реальные записи Wikidata, CC0): Грузия — 16 вузов, 8 школ; Казахстан — 12 вузов, 4 колледжа, 5 школ. Все помечены `is_test`. Скрипт: `scripts/build-seed.mjs`.
- Тесты: Vitest — 68 (контраст, переводы, фильтр, выбор перевода); Playwright — 13 сценариев на десктопе и на мобильном (5 языков, переключение языка и темы, фильтры, поиск → карточка → страница, 404, отсутствие горизонтальной прокрутки).

### Осталось (руками владельца)
1. Создать проект Supabase, выполнить два SQL-файла, положить ключи в `.env.local` (docs/SETUP_GUIDE.md, часть 2). Подключение к Supabase я проверить не мог: у меня нет ваших ключей.
2. Выложить код на GitHub и подключить Vercel (часть 3). Первый деплой проверим вместе.

### Решения
- **Вторая страна — Казахстан**, провайдер карты — **OpenFreeMap** (по ответам владельца). Тестовые данные хранятся в Supabase.
- **База открыта на чтение для всех строк `institutions`** (ТЗ, раздел 12: на карте показываются базовые данные и без проверенной карточки). Записи в БД через публичный ключ невозможны; админ-права — этап 4. Черновые данные карточек будут жить в отдельной таблице `drafts` (раздел 16), а не в `institutions`.
- Цвет и иконка типа пока заданы в коде и в CSS-токенах (`--type-*`), в БД они продублированы (`institution_types`). На этапе 4 справочник станет редактируемым — тогда источник истины переедет в БД.
- Страница `/institutions/...` на этапе 1 — заглушка, не полноценная карточка.
- Плагин `next-intl/plugin` не используется: он грузит `@swc/core`, который в этом окружении не стартует (приложение Claude выдало своей песочнице права на `AppData\Local`, и SWC отказывается хранить там кэш). Алиас `next-intl/config` задан вручную в `next.config.ts`; для наших задач этого достаточно.
- Воркер MapLibre копируется в `public/maplibre/` скриптом перед `dev`/`build` (сборщик не умеет подключать его сам). Папка в git не хранится.
- Эмодзи/иконки: набор из 6 простых иконок нарисован вручную (`src/lib/institutions/icons.ts`), одни и те же пути для легенды и для карты.
- Git-автор в этом репозитории: Timur Dimitriev <bershadskytimur@proton.me> (локальная настройка, глобальную не трогал).

### Открытые вопросы владельцу
1. **Спорные территории.** Из тестовых данных я убрал Абхазский и Южно-Осетинский государственные университеты (раздел 5: решать вам). Вопрос шире: как подписывать такие территории и какие границы показывать на карте (OpenFreeMap рисует границы по данным OSM).
2. **Нет точек для трёх типов** (языковые школы, подготовительные программы, техникумы): в Wikidata для Грузии и Казахстана таких записей нет, сервис OpenStreetMap (Overpass) во время работы не отвечал. Счётчики показывают 0. Данные подберём на этапе 4 (импорт из OSM) или соберём по DATA_COLLECTION.md.
3. **Переводы** на грузинский, китайский и испанский сделал я; перед запуском их стоит показать носителям. Названия городов в тестовых данных пока только на английском (на других языках показываются по-английски).
4. **Контакты поддержки:** нужен адрес почты для страницы «Контакты» (форма — позже).
5. **Доступность карты с клавиатуры.** Точки на карте (canvas) не выбираются клавишей Tab; альтернатива — поиск со списком подсказок (работает с клавиатуры). Полноценный список заведений рядом с картой можно добавить позже.

### Известные ограничения
- Supabase отдаёт максимум 1000 строк за запрос; для десятков тысяч точек (этап 6) нужна загрузка по видимой области или векторные тайлы.
- Страница главной обновляется раз в час (`revalidate = 3600`), поэтому изменения в базе появляются не мгновенно.
