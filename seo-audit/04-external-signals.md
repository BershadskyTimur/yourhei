## 1. Ссылочный профиль

**Данных нет.** Доступа к ссылочным базам (Ahrefs, Semrush, Moz — платные) нет и подключать их без вашего согласия я не буду. Бесплатно ссылки можно посмотреть:

| Где | Как | Что прислать |
|---|---|---|
| Google Search Console | «Ссылки» (в меню слева) → «Внешние ссылки»: «Сайты, ссылающиеся чаще всего» → «Экспортировать» | `gsc-links.csv` |
| Bing Webmaster Tools | «Backlinks» → «Export» (там же есть сравнение с сайтами конкурентов, например mastersportal.com) | `bing-backlinks.csv` |

Ожидание: сайту ~3 недели в индексе, внешних ссылок скорее всего единицы.

## 2. Где получать качественные ссылки (без спама и покупки)

| Источник | Что сделать | Почему сработает |
|---|---|---|
| **Сами вузы** (≈5 700 страниц) | Письмо в международный отдел: «Ваша страница на YourHEI, проверьте данные» + бесплатное управление страницей (раздел «Для вузов» уже есть). Часть поставит ссылку «Мы на YourHEI» | Ссылки с `.edu`/`.ac.*` доменов — самые сильные в теме |
| **Wikidata** | Мы уже используем её данные (CC0). Добавлять исправления, найденные при сборе цен (официальный сайт вуза и т. п.) — без ссылок на себя | Узнаваемость у сообщества, не ссылка |
| **Национальные порталы** «Study in …» | Study in Czechia, Study in Finland, Study in NL, DAAD — у них бывают разделы «полезные ресурсы для иностранцев». Письмо с описанием календаря сроков по стране | Тематические авторитетные сайты |
| **Посольства/культурные центры, программы стипендий** | Наши статьи о стипендиях со сроками и источниками (Türkiye Bursları, Stipendium Hungaricum, Visegrad) — предложить как справку для страниц «Обучение за рубежом» в посольствах Грузии, Армении, Казахстана | Ссылки с гос. доменов в целевых странах |
| **Школы и учебные центры** в Грузии, Армении, Казахстане, Узбекистане (выпускные классы, курсы IELTS) | Предложить чек-лист документов и календарь сроков как бесплатный материал для учеников | Естественные ссылки + целевая аудитория |
| **Сообщества**: Reddit (r/studyAbroad, r/germany, r/Netherlands), Telegram-каналы и чаты абитуриентов, VK/Facebook-группы | Отвечать на конкретные вопросы ссылкой на конкретную страницу (статья, сроки, цена вуза). Не рекламировать | Трафик и упоминания бренда (ИИ-поиск их учитывает) |
| **Каталоги образовательных сервисов и стартапов** | Product Hunt, AlternativeTo (как альтернатива Mastersportal), каталоги EdTech | Несколько ссылок, бренд |
| **Журналисты и блогеры** об образовании за рубежом (ru/en) | Рассылка с исследованием из п. 3 (данные, которых нет у других) | Самые ценные ссылки — из СМИ |
| **Открытые данные** | Опубликовать набор данных цен (агрегированный) на Kaggle / GitHub с атрибуцией источников | Ссылки от исследователей; проверить лицензии источников (CRICOS, College Scorecard — открытые) |

Чего не делать: покупать ссылки, обмениваться ссылками массово, PBN, комментарии-спам, размещение в «каталогах ссылок».

## 3. Контент, который сам собирает ссылки (10 идей)

Все — на данных, которые уже есть в базе; ничего не выдумывать, в каждом — раздел «как считали».

1. **Индекс стоимости учёбы за рубежом 2027**: медиана цены для иностранцев по странам и уровням + стоимость жизни (`living-costs.json`) = «полная цена года». Обновлять раз в год → журналисты цитируют.
2. **Калькулятор бюджета учёбы**: страна + город + уровень → обучение + жизнь + сбор за визу + доказательство средств (суммы уже в статье о визах). Публичная страница без регистрации.
3. **«Где учиться бесплатно в 2027»**: интерактивный список программ с ценой 0 (Германия, Чехия на чешском, Финляндия для ЕС и т. п.) с фильтром по гражданству.
4. **Карта сроков подачи 2027**: календарь (уже есть) + выгрузка в Google Calendar/ICS по стране. ICS-файлы охотно ставят у себя школы и консультанты.
5. **Сравнение требований к английскому**: минимальные IELTS/TOEFL по странам и уровням из данных программ («какой IELTS нужен в Нидерландах на магистратуру»).
6. **Стипендии для граждан Кавказа и Центральной Азии** (статья есть) → сделать таблицу-инструмент «моё гражданство → доступные стипендии» (проверка гражданства уже есть в подборе).
7. **Рейтинг «доступности» стран**: стоимость + право на работу + виза после выпуска + бесплатные программы (данные справок стран). Обязательно открыть методику.
8. **Сравнение «Германия vs Чехия vs Польша»**: цена, язык, работа, сроки — на данных базы.
9. **Ежегодный отчёт «Международные программы на английском в Европе»**: сколько программ, где растёт, средняя цена (из загрузок Study in NL, Studyinfo, universityadmissions.se, DAAD).
10. **Виджет для вузов** «Сроки и цены на YourHEI» (бейдж со ссылкой) — для вузов, которые взяли страницу под управление.
