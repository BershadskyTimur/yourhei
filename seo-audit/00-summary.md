# SEO YourHEI: итог (07.11.2026)

Файлы: `01-search-data.md` (данные поиска), `02-technical-audit.md`, `03-content-semantics.md`, `04-external-signals.md`, `action-plan.md`, `06-measurement-plan.md`.
Сейчас: 39 кликов, 6 820 показов, CTR 0,6 %, средняя позиция 41,9 за 3 месяца (Google, с экрана владельца); сайт в индексе ~3 недели, показы растут.

## 5 главных проблем
1. **75 % страниц вузов — «сироты»**: на 4 270 из 5 713 вузов нет ни одной HTML-ссылки с сайта, Google знает их только из sitemap.
2. **Средняя позиция 41,9**: почти весь сайт на 3–5-й странице выдачи; молодой домен, внешних ссылок почти нет.
3. **Холодный кэш**: первый заход на страницу 4–15 с (Googlebot часто первый).
4. **Мало сигналов доверия (E-E-A-T)**: нет людей/авторов, «О проекте» 124 слова, почта на gmail.
5. **Нет доступа к данным поиска**: анализ запросов (низкий CTR, позиции 4–20, Bing/Яндекс) сейчас невозможен.

## 5 главных возможностей
1. **Страницы вузов + «стоимость»**: люди ищут «<вуз> стоимость / fees», а у нас цены по 5 700 вузам из официальных данных.
2. **Список вузов по странам** закроет перелинковку и запросы «вузы <страны>».
3. **Новые страны и темы из готовых данных**: Швеция (сделано), справки США/Австралии, IELTS-требования, стоимость жизни по городам.
4. **Контент для ссылок**: индекс стоимости учёбы 2027, калькулятор бюджета, ICS-календарь сроков.
5. **Вузы как источник ссылок**: письма «проверьте вашу страницу» → ссылки с доменов вузов.

## Что уже сделано (ветка `seo-audit-nov`, 3 коммита, на сайте ещё нет)
- Title вузов: «Гарвардский университет, США: стоимость обучения и программы», все ≤ 60 знаков (укорачиваются автоматически).
- Швеция: `/study/se` + 19 страниц направлений + сроки подачи (31 вуз).
- Нормальные title у «Страны», «О проекте», «Откуда данные», «Контакты»; описание `/study/<страна>`; title сроков по месяцам; «33 даты» вместо «33 дат»; длинные title направлений укорачиваются.
- Проверено: tsc, lint, 701 тест, сборка, заголовки на локальном сервере (ru/en/de), мобильная ширина.

## Ждёт вашего решения
1. **Слить ветку в `main`** (выкладка) — сейчас или вместе со списком вузов по странам (одна выкладка = меньше трафика Supabase).
2. **Делать ли список вузов страны + видимые хлебные крошки** (задачи №5–6, новый тип страниц).
3. Редирект `http://yourhei.com` → сразу `https://www.yourhei.com` в Cloudflare (продакшн-настройка).
4. Видимые тексты: H1 каталога, title главной, чистка «Pty Ltd»/ВЕРХНЕГО регистра в title.
5. Данные для E-E-A-T: кто автор/команда, почта на домене.
6. Разрешение проверить скорость через PageSpeed Insights (внешний сервис Google, отправляются только публичные адреса).
