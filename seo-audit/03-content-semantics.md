## 2. Пробелы (что создать)

Приоритет по пользе для поиска и по наличию данных (выдумывать ничего не нужно — данные уже в базе):

1. **Список вузов страны** `/institutions/<страна>` — сейчас 404. Это одновременно (а) ответ на «вузы <страны>», (б) HTML-ссылки на каждую страницу вуза. Сейчас ~5 700 страниц вузов связаны в основном через карту сайта (см. `02-technical-audit.md`, раздел «перелинковка»).
2. **Швеция** не попала в страницы направлений: в базе 31 вуз и 1 049 программ (загружены 29.10), а `/study/se` нет — файл `COMBOS` собран до загрузки (перезапустить `scripts/build-study-combos.mjs`). Справки `/countries/se` тоже нет.
3. **Справки стран для США и Австралии** — там 3 330 и 1 540 вузов, больше всего страниц, но справок о визе/работе/жизни нет (есть только 7: DE, GB, NL, FI, CZ, PL, TR).
4. **Языковые требования**: страница или статья «Какие баллы IELTS/TOEFL нужны» — считается из минимальных баллов программ в базе (по стране и уровню), как статья о ценах.
5. **Стоимость жизни по городам** — данные уже есть (`data/reference/living-costs.json`), статьи нет.
6. **Города**: «учёба в Праге / Мюнхене / Мельбурне» — позже, когда будет список вузов по стране (иначе тонкие страницы).
7. **FAQ по поступлению** на справках стран (`FAQPage` на основе уже написанного текста справки) — после проверки, что вопросы в тексте видимы.

## 4. E-E-A-T (опыт, экспертиза, авторитетность, доверие)

| Сигнал | Есть? | Комментарий |
|---|---|---|
| Авторство | **Нет** | Автор статей — «редакция YourHEI» (`Organization`); на «О проекте» 124 слова, нет имён. Нужно решение владельца: имя/роль автора или хотя бы описание команды |
| Контакты | Частично | Страница «Контакты» с адресом почты (gmail). Почта на своём домене (`hello@yourhei.com`) выглядит надёжнее |
| Источники данных | **Да, сильная сторона** | «Откуда наши данные» перечисляет источники; статьи со ссылками на официальные страницы и датой проверки; данные Wikidata/OSM с атрибуцией |
| Дата обновления | Частично | У статей есть `published`/`updated` и `dateModified` в разметке. У страниц вузов даты обновления данных в видимом тексте и в карте сайта (`lastmod`) нет |
| Юридическое лицо | Нет | В `Organization` нет `address`/`legalName`; если юрлица нет — не добавлять |
| Отзывы | Есть блок «Отзывы студентов» | Разметку `Review/AggregateRating` **не добавлять**, пока отзывов мало и они не проверены (риск ручных санкций) |
