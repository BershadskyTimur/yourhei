# Этап 6. План измерений

Отсчёт — от дня выкладки (слияния ветки в `main`). Пример: если выложить 09.11.2026, проверки **23.11** (2 недели), **07.12** (4 недели), **04.01.2027** (8 недель). Search Console отстаёт на ~2 дня, отчёт об индексировании — до 2 недель. Трафик маленький (39 кликов за 3 месяца), поэтому сравнивать надо **показы и позиции**, а не клики: изменения в кликах в пределах нескольких штук — шум.

## Что смотрим по каждому изменению

## Как смотреть

### Google Search Console
1. **Эффективность → Результаты поиска** → «+ Новый» → **Страница** → «Содержит URL» → `/institutions/` (группа вузов). Включить CTR и позицию.
2. «Дата» → **Сравнить** → «Пользовательский»: 14/28/56 дней после выкладки против такого же периода до. Экспорт CSV → положить в `seo-audit/data/`.
3. Фильтр **Запрос** → «Содержит» → `стоимость` (и отдельно `fees`, `tuition`, `цена`).
4. **Индексирование → Страницы**: число «Проиндексировано», причины «Обнаружено — не проиндексировано». Кнопка **Проверить исправление** не нужна — это не ошибка.
5. **Проверка URL**: для 3–5 важных новых адресов (`/ru/study/se`, `/ru/deadlines/se`) → «Запросить индексирование».
6. Аннотация: в GSC нет заметок — записывайте дату выкладки в `PROGRESS.md`.

### Bing Webmaster Tools
1. **Search Performance** → период → вкладка Pages, фильтр по `/institutions/`; Keywords — по словам «fees», «tuition».
2. **URL Submission** → отправить новые адреса (до 100 в день; IndexNow для Bing у нас пока отвечает 403).
3. **Site Explorer** → сколько адресов проиндексировано по папкам.

### Yandex Webmaster
1. **Поисковые запросы → Статистика запросов** → фильтр по группе «стоимость»; показатели: показы, клики, средняя позиция показа, CTR.
2. **Индексирование → Страницы в поиске** → «Последние изменения» (добавленные/удалённые).
3. **Индексирование → Переобход страниц** → новые адреса (лимит в день); плюс `node scripts/indexnow.mjs <адреса>` — Яндекс принимает.

### Своя проверка после каждой выкладки
`python -X utf8 scripts/seo-audit.py` — все 200, без флагов; повторный обход ссылок (скрипт из этого аудита можно добавить в `scripts/`, если нужно).
