# SEO-аудит YourHEI (www.yourhei.com)

Дата: 08.11.2026. Проверено по коду (ветка `main`, коммит `8905876`) и по живому сайту (запросы с User-Agent Googlebot, без выполнения JS).
В коде на этом этапе **ничего не менялось** — только этот отчёт.

Как проверялось:
- `python scripts/seo-audit.py` (robots, карта сайта, 56 страниц всех типов) — все 200, дублей title нет;
- ручные `curl` главной, вузов, каталога с фильтрами, списков, блога, 404, редиректов;

## Топ-5 изменений с максимальным эффектом

1. **Сделать страницы вузов полезнее, а пустые — закрыть** (проблема 1). Это главный вход из поиска («<вуз> стоимость»), и главный риск при обновлениях Google. Шаги: правило `noindex` для страниц без цены, сроков и с ≤ 2 программами; блоки «Стоимость жизни в городе», «Похожие вузы», «Цена против средней по стране», «Ближайшие сроки».
2. **Доверие к сайту (E-E-A-T)** (проблема 2): нормальная страница «О проекте», почта на домене, автор/редактор статей, честное описание процесса с ИИ на «Откуда данные». Дёшево по коду, но нужны ваши данные.
3. **Видимые хлебные крошки + уровень «город» + «похожие вузы»** (проблемы 4, 5): перелинковка страна → город → вуз, совпадающая с разметкой. Больше страниц за визит, быстрее обход.
4. **Шрифты и вес HTML** (проблемы 3, 7): на медленном мобильном интернете (Африка, Центральная Азия, Латинская Америка) это ~1 с к появлению текста.
5. **Открыть следующие языки после вычитки — начиная с грузинского** (проблема 6), и 1–2 статьи в неделю по темам из раздела 7. Внешние ссылки (письма вузам, сообщества абитуриентов — `seo-audit/04-external-signals.md`) идут параллельно, это делаете вы.

## Что уже сделано хорошо

- **Серверный рендеринг.** Googlebot получает весь текст в исходном HTML: на странице Гарварда ~4 300 слов, программы, цены, FAQ — без JS.
- **Правильные коды и адреса:** `http` → `https`, без `www` → `www` (301); слэш в конце убирается (308); `/RU` → `/ru`; несуществующие страницы и вузы отдают настоящий 404 с `noindex`; `/sitemap.xml` → карта сайта.
- **Чистая карта сайта:** 13 673 адреса, без дублей, только индексируемые языки, у каждого адреса hreflang; в ней только вузы с программами.
- **canonical на каждой странице**, сам на себя; адреса с фильтрами и поиском каталога ведут canonical на каталог, служебные разделы и `?_rsc=` закрыты в `robots.txt`.
- **hreflang:** на странице и в карте сайта, взаимный, с `x-default` (английский); закрытые языки не попадают в hreflang. `lang` и `dir` у `<html>` верные (арабский — `rtl`).
- **Переведены не только кнопки, но и title, description, H1** (проверено на ru, en, de, es, zh, ka). Машинный перевод честно помечен плашкой.
- **Человекочитаемые адреса:** `/ru/institutions/us/harvard-university`, `/ru/study/de/082-forestry`, `/ru/blog/proof-of-funds-student-visa`.
- **Уникальные title и description** со смыслом: «Гарвардский университет, США: стоимость обучения и программы», в описании — реальная цена из данных («61 676 $ в год»). Длина контролируется (`fitTitle`, `trimDescription`), падежи — `placeIn()`.

- **Структурированные данные** валидны (JSON разбирается, схемы верные): `Organization`, `WebSite`, `CollegeOrUniversity` со ссылкой на Wikidata (`sameAs`), `FAQPage` (с текстом, который есть на странице), `BreadcrumbList`, `Article` с датами.
- **Источник и дата у данных:** на каждой карточке программы — источник с лицензией и учебный год, внизу «Данные проверены <дата>», ссылка «Сообщить об ошибке».
- **Списки вузов по странам** (`/institutions/<страна>`, постранично) — у каждого вуза теперь есть входящая HTML-ссылка.
- **Статьи блога** со ссылками на официальные источники (14 внешних ссылок в статье о сумме для визы), датами, оглавлением, «Читайте также», RSS.
- **Политика конфиденциальности, условия, контакты, «Откуда данные»** — есть.
- **Скорость сервера:** 0,1–0,3 с из кэша, ~1,5 с без кэша (раньше было 4–15 с); сдвиг макета (CLS) 0–0,02 — отлично; мобильная вёрстка без горизонтальной прокрутки (ширина 360 px), `viewport` верный.

### 2. Мультиязычность

- Структура `/<язык>/…` — правильная (лучше параметров и поддоменов для такого сайта).
- Пример страницы вуза `ru`: `hreflang` ru, en, x-default → en. Главная `es`: ru, en, es, zh, de, fr, pl, x-default. Закрытые версии (`ka`) не имеют hreflang и стоят `noindex, follow` — это согласовано.
- Коды языков без региона (`ru`, `zh`) — верно для сайта без привязки к стране. Для `zh` — упрощённое письмо (`简体中文`); если когда-нибудь будет традиционное, нужен `zh-Hant`.

### 3. On-page

- Title ≤ 60 знаков, description 90–160 — соблюдается (дублей title в выборке 56 страниц нет).
- H1: один на странице. Слабые H1: каталог («Каталог»), «О проекте» (title длиннее и лучше).
- Изображений на страницах почти нет (`<img>` = 0), поэтому проблем с `alt` нет; карта MapLibre рисуется на canvas.
- OG и Twitter: есть на всех страницах, но картинка одна общая (проблема 10).
- Перелинковка: вуз → «Справка: учёба в стране», «Все вузы страны», «Популярные направления», «Страница страны»; статьи → каталог и другие статьи. Не хватает: город, похожие вузы, статьи → конкретные вузы.

### 5. Качество контента и риски

**Страницы вузов.** Медиана — 1 400 слов, четверть — меньше 505, минимум 168. Объём сам по себе не главное: Google оценивает, есть ли у страницы ценность, которой нет в другом месте. Сильные стороны: реальные цены по программам, источник и лицензия, дата проверки, перевод цены в выбранную валюту, FAQ. Слабые: 85 % вузов — из баз США и Австралии, требования к поступлению не заполнены почти нигде, у ~17 % нет цены, все страницы одного шаблона.

**Риск «scaled content abuse».** Политика Google направлена против страниц, сделанных в массе *ради поиска* и без пользы. У вас есть защитные признаки (официальные данные, источники, проверка, честные «нет данных»), но 5 700 однотипных страниц + ~600 страниц «направление × страна» и ~100 страниц «сроки по месяцам» (некоторые ~130–200 слов) — это та зона, где алгоритм может понизить весь раздел. Защита — проблема 1 (закрыть пустые, добавить уникальные блоки) и честное описание процесса с ИИ. Сам по себе ИИ Google не наказывает, наказывает отсутствие пользы.

**E-E-A-T** — проблема 2. Есть: политика, условия, контакты, методика, источники. Нет: людей, истории проекта, почты на домене, описания проверки.

**Что добавить, чтобы быть полезнее конкурентов** (только из реальных данных):
- полная стоимость года: обучение + жизнь в городе (данные есть), + обязательные расходы (виза, страховка) из справок стран;
- сравнение двух–трёх вузов рядом (раздел `/compare` есть, но закрыт от роботов — можно сделать открытые статичные сравнения популярных пар);
- требования к поступлению: минимальный IELTS/TOEFL (у части программ есть), документы;
- ближайшие дедлайны прямо на странице вуза;
- признание диплома в странах аудитории (Казахстан, Узбекистан, Грузия…) — уже есть страница рейтингов/признания;
- стипендии, доступные в этом вузе/стране.
