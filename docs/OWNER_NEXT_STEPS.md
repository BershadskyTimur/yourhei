# Что нужно сделать вам после последних доработок (по шагам)

Всё остальное я уже сделал и выложил на сайт. Три шага ниже нужны, чтобы новые возможности заработали полностью. Без них сайт работает, просто эти части показывают меньше.

## Шаг 1. Два SQL-запроса в Supabase (5 минут)
Supabase → SQL Editor → New query → вставьте содержимое файла → Run. Каждый файл отдельно, по порядку:
1. `supabase/migrations/0026_scholarship_eligibility.sql` — добавляет в стипендии список стран, чьи граждане могут подать заявку.
2. `supabase/migrations/0027_study_institutions.sql` — ускоряет страницы «Учиться на направлении в стране».
3. `supabase/migrations/0028_map_foundation_flag.sql` — фильтр «Подготовительные программы» на карте начнёт находить и университеты, у которых есть подготовительные программы (сейчас без этого только 3 отдельных подготовительных колледжа).
4. `supabase/migrations/0029_admin_tools.sql` — новые разделы админки (здоровье данных, популярные заведения, дубликаты, жалобы на ошибки, состояние сайта) и форма «Сообщить об ошибке» на страницах заведений.
5. `supabase/migrations/0030_admin_data_health_by_country.sql` — делает вкладку «Здоровье данных» быстрой (считает по странам по очереди, иначе упирается в лимит времени).
6. `supabase/migrations/0031_admin_data_health_small.sql` — делает «Здоровье данных» ещё надёжнее: каждая цифра считается отдельным маленьким запросом.
7. `supabase/data/scholarships_national.sql` — **после** 0026: загружает 20 стипендий (13 прежних и 7 новых: NL Scholarship, Swiss Excellence, Visegrad, Bolashak, «Эл-юрт умиди», Чехия, Шведский институт). После этого на странице «Стипендии» работает фильтр по гражданству.

Каждый файл должен закончиться сообщением «Success».

## Шаг 2. Загрузка подготовительных программ — СДЕЛАНО
Программы Великобритании (29 740, из них 4 074 подготовительных) и Австралии (15 882) загружены, ключ из `.env.local` убран. Ничего делать не нужно.

## (старая инструкция, для справки) Загрузка подготовительных программ
1. Supabase → Project Settings → API → скопируйте ключ **service_role**.
2. Откройте `.env.local` в папке проекта, допишите новой строкой `SUPABASE_SERVICE_ROLE_KEY=ваш_ключ`, **сохраните файл** (Ctrl+S).
3. Напишите мне «ключ есть». Я загружу программы Великобритании (с добавленными подготовительными годами) и Австралии и переведу заведения, у которых только подготовительные программы, в тип «подготовительные».
4. После загрузки я скажу удалить строку с ключом.
