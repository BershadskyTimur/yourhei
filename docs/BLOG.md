# Блог YourHEI: как устроен и как добавить статью

Стратегия и темы — в [SEO_STRATEGY.md](SEO_STRATEGY.md). Здесь — рабочая инструкция.

## Правила

- Блог выходит на **русском и английском**. Остальные 14 языков видят английский текст (с пометкой), эти страницы закрыты от поисковиков (`noindex`).
- **Ничего не выдумываем.** Каждый факт взят с официальной страницы или из данных проекта (`data/countries/guides.json`, `data/scholarships/national.json`, `data/reference/living-costs.json`). Таблицы в статьях подтягиваются из этих файлов автоматически, поэтому правка данных обновляет и статью.
- Каждая статья заканчивается пометкой «не юридическая консультация» (она добавляется сама) и ссылками на официальные страницы.
- Темп: 1–2 статьи в неделю. Статьи можно готовить заранее: у каждой есть дата `published`, раньше этого дня статья не видна (страницы пересобираются раз в час). Первые 12 статей опубликованы сразу 24.10.2026 по решению владельца.

## Как добавить статью

1. Скопируйте любой файл из `src/content/blog/` под новым именем, поменяйте `slug` (латиница, через дефис, одинаковый для обоих языков), `published` и `updated` (формат `2026-11-16`; `updated` не раньше `published`).
2. Заполните `ru` и `en`: `title` (до 70 символов), `description` (90–170 символов, это текст под заголовком в поиске), `blocks`.
3. Добавьте статью в список `ARTICLES` в `src/lib/blog/posts.ts`.
4. Запустите `npm test`: тест проверит оба языка, одинаковую структуру, даты и ссылки.

## Блоки статьи

| Блок | Что делает |
|---|---|
| `{ t: 'p', text }` | абзац; внутри можно `**жирный**` и `[текст](/catalog)` (адрес страницы сайта или `https://…`) |
| `{ t: 'h2', id, text }` | раздел; `id` одинаков в обоих языках, из них собирается оглавление |
| `{ t: 'h3', text }` | подраздел |
| `{ t: 'ul' / 'ol', items }` | списки |
| `{ t: 'note', text }` | выделенная заметка |
| `{ t: 'cta', href, text }` | кнопка-ссылка на страницу сайта (подряд идущие кнопки стоят в один ряд) |
| `{ t: 'rules', topic: 'work' \| 'after' }` | правила стран: работа во время учёбы / после диплома |
| `{ t: 'funds' }` | суммы, которые страна требует показать для визы |
| `{ t: 'scholarships', covers, level }` | стипендии: фильтр по покрытию и уровню |
| `{ t: 'scholarshipsFor', countries }` | стипендии, открытые гражданам перечисленных стран |

Ссылка на статью, которая ещё не опубликована, показывается простым текстом (не битой ссылкой) и сама оживает в день публикации.

## Как прочитать статьи до публикации

Запустить сайт с переменной `BLOG_SHOW_ALL=1` (в `.env.local`, только у себя, на сайт её не добавлять) или выбрать конфигурацию `yourhei-blog-review` в `.claude/launch.json`: она открывает сайт на порту 3001 и показывает и запланированные статьи.

## Что получает поисковик

Адрес (`canonical`), ссылки между ru и en (`hreflang`), `Article` и `BreadcrumbList` (JSON-LD), даты публикации и изменения, лента `/ru/blog/feed.xml` и `/en/blog/feed.xml`, запись в карте сайта с датой изменения.
