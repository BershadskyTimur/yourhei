## Отклонено (разбор сторонних отчётов 17–18.11, не возвращаться без новых данных)

- ТЗ от 18.11 («реанимация индексации», шесть эпиков): большая часть уже сделана или отклонена выше. Уже есть: ISR на сутки для вузов и списков, `robots.txt` 200, карта сайта (`/sitemap.xml` даёт 308 на `/sitemap/0.xml`, она 200), FAQ и JSON-LD (`CollegeOrUniversity`, `BreadcrumbList`, `FAQPage`) у США, одна строка источника вместо 82 (коммит `82301b3`), `noindex` для «тонких» страниц, входа и непереведённых языков, самоссылающийся canonical, hreflang только между открытыми языками и `x-default`. Не подходит: Vercel (у нас Cloudflare Workers + OpenNext); открытие `uk`, `pl`, `tr`, `kk` для поиска (решение 17.11: закрыто, пока человек не прочитал переводы); замена «Похожих» на рейтинговые (см. C.1); смена слагов (см. выше).
- Cookie `NEXT_LOCALE` на публичных страницах (проверено 18.11): next-intl 4.14.9 ставит её только запросам без заголовка языка (боты, curl) или когда язык страницы не совпадает с языком браузера. Роботу Google она не мешает, кэш Cloudflare для HTML не используется. Менять не нужно.

- Cloudflare «Cache Everything» для HTML — у сайта своё кэширование (OpenNext), правило ломает журнал визитов и обновление страниц.
- Смена адресов (слагов) и 301 — у страниц, которые Google уже выкинул, это обнулит историю.
- Разметка FAQ как `CollegeOrUniversity` — неверный тип; FAQ уже есть на всех вузах с данными (`FAQPage`).
- «Опечатка Қзақша», «230 тыс. страниц на 16 языках», «robots.txt и sitemap недоступны» — проверено 18.11, неверно.
- Ручная отправка 20 страниц на переиндексацию — ждём результат по Гарварду.
