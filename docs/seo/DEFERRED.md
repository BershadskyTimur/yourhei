## B. Можно делать в любой момент (не шаблоны выдачи)

2. **Обновить Next.js до 16.4.4+** (уязвимость GHSA-mfr8-8qww-v76h; `next build` локально останавливается сообщением о ней). Отдельная ветка, полный прогон проверок, одна выкладка.
3. **Кэш страниц не обновляется до следующей выкладки** (OpenNext 1.20.12: устаревшая страница не перестраивается, `STALE` через час после сборки). Не чинить без замера нагрузки на базу.
4. ~~Переводы двух статей о стоимости (Австралия, Нидерланды) на 14 языков~~ — сделано 18.11.2026 (`src/content/blog/i18n/<язык>-more6.ts`).
5. **Пересобирать список вузов из рейтингов** после загрузки рейтингов или обновления `thin-institutions.json`: `node --env-file=.env.local scripts/build-ranked.mjs`.

## C. Решить после оценки ~01.12 (меняют все страницы вузов)

1. **«Похожие заведения»** сейчас — соседи по алфавиту (`src/lib/institutions/similar.ts`): это специально, так на каждую из ~5 000 мелких страниц ведут ссылки. Не заменять. Вариант: у вуза из рейтингов **добавить** 3–4 других вуза из рейтингов той же страны (из `data/generated/ranked-institutions.json`, без чтения базы), алфавитных соседей оставить.
2. **Подзаголовки (H2) с названием вуза** («Сколько стоит обучение в {вуз}», «Программы {вуз}» вместо «Стоимость по уровням», «Программы»). Тексты — во всех файлах переводов.
3. **Title и description** страниц вузов (последний раз меняли 09.11). Только если выгрузка 01.12 покажет, что страницы на 1-й странице выдачи без кликов, и только с реальными данными из базы (цена, срок). Не выдумывать цифры.
4. **Уровень «Колледж» (Associate) у Гарварда и других вузов США** стоит первой строкой в «Стоимости по уровням». Проверить, верны ли данные College Scorecard, и порядок уровней (`LEVEL_ORDER`).
5. **Внутренние ссылки из статей блога** на вузы других стран (как сделано для Польши в `src/lib/blog/article-institutions.ts`): только вузы, упомянутые в тексте статьи.

## Отклонено (разбор сторонних отчётов 17–18.11, не возвращаться без новых данных)

- Cloudflare «Cache Everything» для HTML — у сайта своё кэширование (OpenNext), правило ломает журнал визитов и обновление страниц.
- Смена адресов (слагов) и 301 — у страниц, которые Google уже выкинул, это обнулит историю.
- Разметка FAQ как `CollegeOrUniversity` — неверный тип; FAQ уже есть на всех вузах с данными (`FAQPage`).
- «Опечатка Қзақша», «230 тыс. страниц на 16 языках», «robots.txt и sitemap недоступны» — проверено 18.11, неверно.
- Ручная отправка 20 страниц на переиндексацию — ждём результат по Гарварду.
