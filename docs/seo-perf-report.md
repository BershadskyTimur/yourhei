# Скорость и SEO: отчёт «до и после»

Дата: 14 ноября 2026. Ветка `seo-perf`, **на сайт не выложено**. Замеры «до» — в [seo-perf-baseline.md](seo-perf-baseline.md).

## Важно про цифры «после»

- «До» измерено на живом сайте `www.yourhei.com`.
- «После» измерено на этом компьютере: продакшн-сборка ветки, запущенная локально (`next start`). Lighthouse в обоих случаях замедляет сеть и процессор одинаково, но локальный сервер отвечает за 5 мс, а живой — за 80–120 мс.
- Поэтому на живом сайте после выкладки FCP и LCP будут примерно на 0,3–0,6 с больше, чем в столбце «после». Точные цифры даст повторный замер после выкладки: `node scripts/lighthouse-run.mjs https://www.yourhei.com lighthouse-out 3`.
- Best Practices 100 локально не доказывает, что две ошибки консоли исчезнут на живом сайте: обе возникают только на Cloudflare. Исправления внесены, проверить их можно только после выкладки.

## Что не достигнуто и не сделано

| Пункт | Почему | Что можно сделать |
|---|---|---|
| Цифры «после» на живом сайте | Ветка не выложена | Замерить после выкладки той же командой |
| Области нажатия 48 px | Сейчас 25–40 px (норма WCAG 2.2 AA — 24 px). Довести всё до 48 px значит заметно изменить вид шапки и списков | Решение за вами |
| `lastmod` в карте сайта | Есть только у статей (175 из 13 680). Для вузов нужна дата из базы, а это дополнительный трафик Supabase при каждой сборке карты | Сделать после решения вопроса с квотой Supabase |
| HTML больших вузов (427 КБ у Гарварда) | Все программы выводятся сразу; сокращение меняет вид страницы | Показывать первые 30 программ и кнопку «ещё» — нужно ваше решение |
| Свой title у страницы 404 | В Next.js 16 у вложенной 404 не бывает своих метаданных; код 404 и `noindex` стоят | На поиск не влияет |
| Критический CSS в HTML | Весь CSS — 48 КБ в двух файлах с кэшем на год; выигрыш оценивается Lighthouse в ~0,4 с на медленной сети, а экспериментальная настройка Next.js для этого не проверена на Cloudflare | Можно попробовать отдельно |
| ~100 КБ неиспользуемого JS при первой загрузке | Общий код Next.js, React и клиента Supabase | Без смены архитектуры почти не уменьшить |

## Что нужно сделать вам

### 1. Выложить ветку

Выкладка сбрасывает кэш страниц и расходует трафик Supabase, поэтому лучше объединить её с другими накопившимися правками.

1. Скажите мне «выкладывай» — я солью `seo-perf` в `main` и отправлю.
2. Дождитесь сборки в Cloudflare → Workers → yourhei → Builds.
3. Попросите меня повторить замеры на живом сайте.

### 2. Cloudflare

1. **Один редирект вместо двух.** Сейчас `http://yourhei.com` → `https://yourhei.com` → `https://www.yourhei.com`. Rules → Redirect Rules → Create rule: если Hostname равно `yourhei.com`, то Dynamic redirect на `concat("https://www.yourhei.com", http.request.uri.path)`, код 301, галочка «Preserve query string».
2. **Web Analytics.** После выкладки откройте сайт, нажмите F12 → Console и убедитесь, что красной строки про `cloudflareinsights` больше нет. Если счётчик вам не нужен — выключите его: Analytics & Logs → Web Analytics.

### 3. Google Search Console

1. Sitemaps: убедитесь, что `https://www.yourhei.com/sitemap/0.xml` в статусе «Успешно»; если нет — отправьте заново.
2. «Основные интернет-показатели» (Core Web Vitals): посмотрите через 4 недели после выкладки. Отчёт строится по реальным посетителям за 28 дней; при малом трафике он пуст.
3. «Индексирование страниц»: посмотрите причины в разделе «Почему страницы не индексируются» и пришлите мне скриншот.
4. Проверка разметки: откройте `https://search.google.com/test/rich-results` и проверьте три адреса — главную, любую страницу вуза, любую статью.

### 4. Bing Webmaster Tools

1. Sitemaps → Submit sitemap: `https://www.yourhei.com/sitemap/0.xml` (если ещё не отправлена).
2. Site Scan → запустить проверку сайта после выкладки.

### 5. Решения, которые жду от вас

1. Сокращать ли список программ на страницах больших вузов до 30 с кнопкой «ещё»?
2. Доводить ли все кнопки и ссылки до 48 px ценой более высоких шапки и списков?
3. Оставить ли шрифт устройства в переключателе языков (экономит 87 КБ на каждой странице)?
