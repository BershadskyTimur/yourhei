# Скорость и SEO: базовые замеры (этап 0)

Дата: 13 ноября 2026, живой сайт `https://www.yourhei.com` (код `8d14d68`, до правок ветки `seo-perf`).

## Как устроен сайт

| Что | Как |
|---|---|
| Фреймворк | Next.js 16 (App Router), React 19, TypeScript, Tailwind v4, сборщик Turbopack |
| Хостинг | Cloudflare Workers через OpenNext; статика (`/_next/static`) раздаётся CDN Cloudflare со сжатием Brotli и кэшем на год |
| Рендеринг | Все страницы собираются на сервере и хранятся в кэше (ISR: R2 + региональный кэш Cloudflare). Чистого SPA нет; в браузере догружаются только результаты каталога и карта |
| Данные | Supabase (Postgres); ответы базы кэшируются на сутки |
| Языки | 16 языков в адресе (`/ru`, `/en` …); поисковикам открыты ru, en и частично es, zh, de, fr, pl |
| Изображения | На страницах нет растровых картинок (только `og.png` для превью ссылок и SVG-иконки), поэтому пункты про AVIF/WebP и `srcset` к сайту не применимы |

## Как мерили

`node scripts/lighthouse-run.mjs https://www.yourhei.com <папка> 3` — Lighthouse (Chrome, режимы «телефон» и «десктоп»), каждая страница по 3 раза, в таблице средний из трёх прогонов.

Страницы:

- главная — `/ru`
- каталог — `/ru/catalog`
- страница вуза — `/ru/institutions/us/harvard-university` (самая тяжёлая: сотни программ)
- статья блога — `/ru/blog/how-much-does-it-cost-to-study-abroad-tuition-by-country`

INP в лабораторном замере не измеряется (нужны действия живого человека); вместо него Lighthouse даёт TBT — время, когда страница занята скриптами и не отвечает на нажатия.

## Что уже в порядке

- SEO 100 и Accessibility 100 на всех страницах в обоих режимах.
- Ответ сервера (TTFB) 80–120 мс из кэша.
- Статика: Brotli, `Cache-Control: public, max-age=31536000, immutable`.
- Сдвигов макета нет нигде, кроме каталога на десктопе.
- Заголовки безопасности (HSTS, CSP, X-Content-Type-Options, Referrer-Policy) на месте.
